# My Notepad 📝

A simple, lightweight, and functional text editor built with Python and Tkinter. 

## Features
* **File Management:** Create new files, open existing `.txt` files, and save your work securely.
* **Live Counter:** Real-time tracking of character and word counts at the bottom of the screen.
* **Text Formatting:** Easily adjust text with Bold, Italic, and Underline tags.
* **Font Scaling:** Increase or decrease font size directly from the Format menu.
* **Keyboard Shortcuts:** Supports `Ctrl+N` (New), `Ctrl+O` (Open), and `Ctrl+S` (Save).

## Prerequisites
* Python 3.x
* Tkinter (Usually comes pre-installed with standard Python distributions)

## How to Run
1. Clone this repository to your local machine.
2. Navigate to the project directory.
3. Run the script using the terminal:
   ```bash
   python notepad.py
